# Gradle Wrapper

The Android project is intended to be built with the Gradle Wrapper.

Target wrapper version:

```text
Gradle 8.11.1
```

The repository contains:

```text
gradlew
gradlew.bat
gradle/wrapper/gradle-wrapper.properties
```

The binary `gradle-wrapper.jar` is generated by Gradle itself and is not included in this source-only bootstrap archive.

## Bootstrap once on Arch Linux

If `gradle-wrapper.jar` is missing, install Gradle temporarily:

```bash
sudo pacman -S gradle
```

Then:

```bash
cd android
gradle wrapper
```

After the command completes, verify:

```bash
ls -l gradle/wrapper/
```

You should have:

```text
gradle-wrapper.jar
gradle-wrapper.properties
```

After that, the system Gradle package can be removed if desired:

```bash
sudo pacman -Rns gradle
```

From then on, use:

```bash
./gradlew assembleDebug
```

The wrapper downloads and uses Gradle 8.11.1 independently of the system Gradle version.

## JDK

The project uses JDK 17:

```bash
java -version
```

Do not change the Android project's Java toolchain just because Arch's current Gradle package asks for a newer Java version.
